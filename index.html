Real-Time Embedded Patient Monitoring System

ESP32 • FreeRTOS • Hard-Deadline Medical Monitoring

Project Overview

This project simulates a real-time healthcare monitor designed to track and react to patient vital readings. The system reads an analog health signal, detects threshold exceedances, and triggers alarms within strict timing requirements. Real-time scheduling ensures that life-critical events are processed under deadline, while non-critical UI tasks run in the background without interference.

Key Features

  • ESP32 running FreeRTOS
  • Two LEDs (heartbeat + alarm)
  • Variable-time alarm processing
  • Nurse call button with ISR and software debounce
  • Queue-based sensor event transfer
  • Mutex-protected console output for race-free logging
  • Hard deadlines verified using serial timing prints

Company Scenario

This is a patient monitoring system for use in healthcare technology. The design models an early-stage ICU bedside monitor, where fast responses to changing vital signs are critical, and missed deadlines may indicate real patient risk. Hard tasks handle sensor detection and alarm activation, while soft tasks manage user interaction and device feedback without impacting safety.

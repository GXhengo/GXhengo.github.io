Real-Time Embedded Patient Monitor

Built on ESP32 • FreeRTOS • Hard-real-time alarm path

Project Overview

This project is a real-time monitoring prototype designed to simulate a hospital ICU vital signs system. The ESP32 reads an analog "vital" signal, detects threshold crossings, and triggers an alarm path under strict timing requirements. Hard tasks guarantee fast response to critical levels, while soft tasks handle background UI tasks such as heartbeat LED output and nurse-button interaction.

Key Features

  • ESP32 with FreeRTOS multithreading
  • Two LEDs (status + alarm)
  • Analog sensor threshold detection
  • Hardware button ISR + debounced nurse alert task
  • Queue-based data passing between tasks
  • Mutex-controlled UART output to prevent race conditions
  • Recorded timing proof demonstrating deadline success

Company Scenario

The system is modeled as a VitalCare ICU patient monitor. Hard deadlines simulate medically critical timing (50 ms alarm response, 100 ms sampling). Soft tasks provide system feedback without threatening patient safety.

Real-Time Embedded Patient Monitoring System

ESP32 • FreeRTOS • Hard-Deadline Medical Monitoring

Project Overview

This project simulates a real-time healthcare monitor designed to track and react to patient vital readings. The system reads an analog health signal, detects threshold exceedances, and triggers alarms within strict timing requirements. Real-time scheduling ensures that life-critical events are processed under deadline, while non-critical UI tasks run silently in the background without affecting response time.

Key Features

  • ESP32 running FreeRTOS
  • Two LEDs (heartbeat + alarm)
  • Variable-time alarm processing
  • Nurse call button with ISR and software debounce
  • Queue-based sensor event transfer
  • Mutex-protected console output for race-free logging
  • Hard real-time deadlines measured and proven

Company Scenario

This is a patient monitoring system for use in healthcare technology. The design models an early-stage ICU bedside monitor, where fast reaction to changing vital signs is essential and missed deadlines may signal real patient risk. Hard tasks are responsible for vital sampling and alarm execution, while soft tasks handle nurse input and device feedback. This separation keeps the system responsive even under heavy load.
